# Vetri Fabs India - Mobile Food Truck & Kitchen Fabricators

Official website for **Vetri Fabs India**, premier commercial food truck, mobile food van, and stainless steel kitchen fabricator based in Erode, Tamil Nadu, India.

## 🚀 Overview

- **Custom Food Trucks**: Tata Ace, Mahindra Bolero, Ashok Leyland Dost body fabrication.
- **Mobile Food Vans & Carts**: Modern kiosks, kiosks on wheels, juice carts, banquet live-counters.
- **Stainless Steel Commercial Kitchens**: Heavy-duty SS 304 food-grade fabrication, exhaust hoods, tandoor & shawarma counters.
- **Interactive Features**: Product showcase, interactive quotation builder modal, specs viewer, and direct WhatsApp / phone contact.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 19)
- **Styling**: Tailwind CSS & Modern Vanilla CSS Design Tokens
- **Icons**: Lucide React
- **TypeScript**: Full type safety

## 💻 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## 📦 Build for Production

```bash
npm run build
npm run start
```
